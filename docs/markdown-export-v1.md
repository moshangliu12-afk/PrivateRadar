# 本地 Markdown 导出 V1

入口位于「设置 → 导出聊天 → 导出 Markdown」。选择一个已有会话，选择本地输出目录，再开始导出。默认导出完整会话；已有日期范围能力一并恢复，使用导出开始时的系统本地时区。完整会话包含未知时间消息，日期范围不包含这些消息并明确报告排除数量。

## 恢复与适配

恢复自 `PrivateRadar-export-deferred-archive-20261024-164232`，归档清单与全部 SHA-256 校验通过。归档实际包含三个开发文件：只读选择核心、共享契约及选择专项测试，没有已完成的渲染器、写入器或 UI，也没有多会话选择实现。

保留原核心的一致只读事务、按键分页、确定性顺序、日期及夏令时解释、容量保护、取消、来源关系与附件占位投影。最小适配为读取现有 `user_conversation_label`，调用公共名称 resolver，并调整旧测试中已经过时的按列位置插入。

新增 Markdown renderer、安全文件发布、桌面通信和轻量面板，不修改 Conversation Label 的组件、resolver、表结构或来源同步。开发基线是 `b37a3483440a9b0ca66af40ff53cd38dd78d1d2d`，保留完整 Conversation Label 主体及 UX 修复。

## 输出与名称语义

每次选择一个完整会话 ID；同名会话不会合并。输出为：

```text
所选目录/PrivateRadar/安全名称--会话短摘要--选择短摘要/
  聊天.md
  export.json
```

所选目录已经名为 PrivateRadar 时直接使用；已有同名根目录按大小写不敏感方式识别。目录展示名称和 Markdown 标题使用 `displayConversationName`。元数据分别保留 `sourceConversationName`、`userConversationLabel`、`displayConversationName`，消息及来源 occurrence 的原名称也保持独立。用户名称不会写回来源。

消息正文来自现有规范消息，保持原字节文本，不 trim、不改写换行、不猜测未知发送人或时间。复杂 Markdown、HTML、URL、空白及多行原文使用动态字面文本围栏，围栏长度大于原文最长反引号串。文件为 UTF-8，无 YAML frontmatter，可直接放入 Obsidian。

`export.json` 是轻量核验元数据，不是另一种聊天导出格式。记录导出和模板版本、应用版本、时间、会话与三层名称、范围及计数、按顺序的消息内容摘要、来源登记及附件占位、Markdown 文件大小与 SHA-256。选择摘要排除导出时间、应用版本和机器输出路径，保证重复判断稳定；元数据不包含正文副本、原始内部 metadata、FTS、AI 数据或机器 Evidence 路径。

## 重复与失败保护

同一选择内容、名称和策略完全相同，且已有元数据与 Markdown 摘要一致时，返回已有完整导出。用户修改 Markdown、元数据损坏或缺失时，保留原文件并创建 `--v2`、`--v3` 等新版本。聊天或名称变化形成新的选择摘要。目录身份短摘要遇到可识别的碰撞时扩展，不按名称决定会话身份。

文件名处理 Windows 禁用字符、设备名及上标设备名、空名、控制或方向字符、组合字符和 emoji；按字素限制长度，完整路径不超过 240 个 UTF-16 单元。只接受本地固定 NTFS 普通目录，使用既有 Windows 目录句柄租约拒绝网络路径、路径穿越和重解析跳转。不会改动该公共安全模块。

两个输出文件先写入独占 staging，刷新并核验，再以 Windows 原生 `MoveFileExW(flags=0)` 一次发布整个目录，不替换已有目标。发布前再次检查两文件和哈希。写入中断、取消或发布失败时只清理自身可确认的临时文件；保留未知内容和所有已有用户文件。

主进程保存原生选择器给出的输出目录；界面不能提供数据库路径或替换输出路径。一次只运行一个导出，可取消；打开目录仅使用刚刚成功导出的主进程记录。源数据库路径来自现有桌面入口，读取连接以 `readOnly` 打开同一个文件，不经过初始化、迁移或修复，不创建第二数据库。原数据目录及其下级目录不能作为输出目标。

## 范围与验证

当前支持单会话和已有日期范围，不含附件复制、其他导出格式、同步或插件。附件仅投影已有登记类型和占位，不探测磁盘；Evidence 只引用登记信息，不重新验证、复制或写回。

专项测试覆盖归档核心、Markdown、名称三层语义、正文与元数据哈希、Windows 真实发布、重复和冲突、部分写入失败、取消、源库与关系不变、桌面通信和 UI。另运行必要的 Conversation Label 和设置页回归、类型检查、构建及 MCP 构建。桌面人工验收通过独立 win-unpacked 候选交付，用户先完整备份真实数据目录，再复制校验到普通用户文档目录。

没有版本升级、正式安装器、推送、Tag 或 Release，也不进入下一功能。
