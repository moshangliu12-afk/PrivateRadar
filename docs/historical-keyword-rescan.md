# 扫描历史聊天

基线为 `e6888bb475395fc78ad5f97f738bfd1bbc9739ee`。沿用当前组与启用关键词模型、`matchKeywordSnapshot` 和 `literal-nfc-ascii-v1`；没有第二套历史匹配器。关键词的归档语义、来源事实、会话标签和三种导出格式保持。

## 用户操作与边界

每个启用、未归档组提供“扫描历史聊天”。进入页面只读取状态；启动、创建规则、修改规则和正常导入均不启动全库历史扫描。同一数据库一次只运行一个扫描，可以取消。停用组不能开始扫描；启用但没有启用词的组可以手动扫描，以清理该组旧结果。

扫描冻结当前组的有效规则和开始时的消息、来源上界。正文按消息 rowid 游标分批，最多 128 条、一般不超过 2 MiB；单条较大正文独立处理。来源再按 rowid 分页，每页最多 256 条。批次间让出事件循环，写事务内不等待异步任务；正常查询与导入可在批次间执行。扫描期间新增消息及来源仍走既有导入处理，不计入本次扫描的冻结范围。

每次短事务写入前重读并验证规则快照。修改名称、启停词、停用组或归档会停止旧扫描，提示重新扫描。归档继续保留已存在命中，不增加物理删除规则的产品入口。取消、异常、退出后不会自动续扫，已安全提交的派生结果保留；用户再次完整扫描即可最终校准。状态读取不修改中断任务；下次明确启动才收口中断记录。

## 派生表与结果一致性

仅增量创建两个派生表，不改原消息、来源关系或 Evidence 结构，不重建 FTS，不改变数据库位置，也不更改既有 `user_version=8`。按表检测和事务创建支持重复打开现有数据库。

- `keyword_rescans`：冻结规则、任务拥有进程、状态、进度和统计。全局部分唯一索引防止并行任务。
- `keyword_rescan_coverage`：记录某组已明确重扫覆盖的来源，以及没有附件来源登记的旧消息的直接派生命中。覆盖记录关联冻结任务，防止迟到的旧导入任务恢复已经失效的匹配。

原 `keyword_hits` 强制绑定真实附件来源位置，不能覆盖所有旧 canonical 消息，也无法表达重扫过但已不匹配的位置。新增表用于这两个实际缺口和持久任务状态；不伪造来源登记来满足原外键。

有来源的命中继续写原 `keyword_hits`，去重 identity 继续是 `(group_id, batch_item_id, source_position)`。覆盖表只记录这类位置的规则覆盖，不复制命中正文或词快照。没有来源的旧消息以 `(group_id, message_id)` 唯一关联原文，不制造附件或 Evidence。之后产生真实来源命中时退休对应直接命中；列表也排除已有真实来源命中的重复投影。同文不同消息身份不会合并，同一 canonical 的不同真实来源位置仍保留既有语义。

重扫只校准当前组：新增、更新当前匹配，删除旧失效匹配，保留其他组。相同规则重复扫描不改变原命中编号和发现时间，新增为零。旧的 pending/failed 导入任务处理已覆盖位置时，通过覆盖记录选取最后明确扫描的规则，再调用同一正式 matcher；未覆盖的新来源继续使用原导入冻结快照。规则变化本身不扫描任何历史正文。

## 展示与统计

“已扫描”统计 canonical 消息条数；“命中”按既有来源位置计数，无来源消息直接一处。新增、已有、移除失效均是本次处理范围内的实际计数；扫描期间的新导入不混入冻结范围。单条消息来自多张真实卡片时，命中处数可大于消息数。

会话名统一用现有 `displayConversationName` resolver。聊天时间只来自可靠消息或对应来源时间；扫描时间仅用于操作元数据和发现时间。现有来源命中继续使用原附件 Context/Evidence 导航；无附件消息可查看原文与会话上下文，明确显示未绑定附件并禁用 Evidence 按钮。不会借用其他来源的证据。

## 验证与交付

专项覆盖显式触发、正式 matcher 一致性、Unicode、相同正文不同身份、live/历史去重、迟到导入、规则清理、其他组不变、取消、竞态、失败重试、重启只读、迁移幂等、消息与来源/FTS 字节投影不变、UI 交互以及隔离一万条混合来源扫描。相关回归覆盖关键词雷达、Today 类型兼容、导入、Evidence、Search、会话标签与 Export smoke。

桌面候选固定到独立提交，保持 alpha.24 版本号，不发布。真实数据由用户先关闭 PrivateRadar 和 WorkBuddy、完整备份整个数据目录并核验，再复制候选到自己的 Documents 并逐文件核验后启动。备份不能作为运行数据库，不改数据路径、Junction 或 ACL。技术测试通过与真实桌面人工验收分开记录。
