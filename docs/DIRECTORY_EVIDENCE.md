# Step 5H 目录证据契约

本层仅接收调用方明确传入的本地绝对目录路径，不查找附件，不枚举 WorkBuddy 历史目录，不接入当前输入 Gate 或正式 Batch Tool。消息继续来自 inline transcript Parser；证据中的 `聊天记录.txt` 不参与重新生成消息。

## 数据与结构

数据库版本由 3 升至 4，仅新增 `batch_import_items.evidence_source_kind`，默认 `zip`，可选 `directory`。旧 ZIP 的路径及 SHA-256 不变。

目录项保存为：

```text
evidence/<item UUID>/source/<原目录结构>
evidence/<item UUID>/manifest.json
evidence/<item UUID>/messages.json
```

`evidence_relative_path` 指向 `manifest.json`；`attachment_identity` 是目录内容身份。`saveDirectoryEvidence` 返回的 `sha256` 在此来源类型下表示目录内容身份，不是 ZIP 哈希。实例身份始终是 item UUID；相同内容的不同实例不会合并。

清单包含固定顺序字段：`manifest_version=1`、`source_kind=directory`、`directories`、`files`、`total_file_count`、`total_bytes`、`directory_content_identity`。文件项包含 `path`、`size`、`sha256`。路径保留 Unicode 和大小写，分隔符使用 `/`，按字符串序数排序；目录列表保留空目录。

身份计算为清单前六个字段的固定顺序 `JSON.stringify` UTF-8 字节的 SHA-256，不包含身份字段自身、末尾换行、绝对路径、文件时间或实例编号。清单文件为完整对象的规范 JSON 加一个 LF；校验拒绝不规范清单。

## 安全与一致性

仅支持 Windows 本地固定磁盘。Windows Node 无 `O_NOFOLLOW`，因此使用系统 Windows PowerShell 和 .NET 原生句柄桥接；不安装依赖。固定脚本经编码参数启动，路径仅由标准输入 JSON 传递。所有请求串行执行，有超时与进程故障检测。

从磁盘根到目录及每个文件逐层取得原生句柄，使用 `FILE_FLAG_OPEN_REPARSE_POINT`，拒绝任何重解析点、非磁盘文件、类型不符或多重硬链接。句柄仅允许读取共享，保持至保存或验证完成。文件哈希、复制和清单读取通过已验证的原生句柄执行；不重新按源文件路径打开。能力不可用就拒绝，不降级到普通递归复制。

使用 `lstat`、`realpath`、原生文件类型及路径核验；拒绝绝对清单路径、上级路径、设备/网络路径、ADS、控制字符、危险 Windows 名称及大小写冲突。暂存目标目录逐层创建并锁定；复制采用独占新建。

句柄缓存按精确路径区分，逐层核对句柄实际文件名的原始大小写与 Unicode 字符。路径段必须与实际名称一致；不依赖忽略大小写的匹配接受文件名别名。盘符大小写不受此约束。

源树在复制前后分别枚举、哈希并核对身份和 stat；每次枚举也核对访问前后的 stat，检测读取期间变化。文件内容、增删改名或目录结构无法确认一致即失败。mtime、ctime 等只用于同一次操作的一致性检测，不进入内容身份，更不用于消息时间。

## 限制

集中上限：深度 16；普通文件 4096；全部目录项 8192；单文件 128 MiB；总文件字节 512 MiB；清单 8 MiB。允许测试或调用方降低上限，不允许提高。目录消息快照另限 8 MiB。目录枚举采用流式 `opendir`。这些上限用于控制资源，不能据此声称大量真实附件已验证。

## 发布与验证

暂存在 Evidence 根的唯一兄弟目录，完成复制、源一致性检查、清单生成和实际内容复验后，释放暂存句柄并同盘 rename。最终位置再次验证后才登记可用；现存目标一律拒绝覆盖或接管。受控异常清理本次暂存或尚未登记的发布目录。

同项同内容先验证已有副本再返回，不改写；不同内容或 ZIP/目录类型冲突拒绝。验证只依赖持久目录、清单和可信数据库身份，不依赖 WorkBuddy 临时源。校验完整文件及目录集合，能检测文件修改、增删、改名、空目录变化和清单篡改。

消息快照仍使用原有格式，与该 item 的原始证据分开登记。目录或快照未通过验证时，现有 importer 不会创建任务或消息。原导入器的正文首尾空白处理不在本轮修改范围；持久源文件和消息快照仍分别保留输入字节与解析输入。

## 边界

本轮仅验证隔离目录和数据库。实际卡片接线、长期运行、其他平台、网络卷、外接卷及不同 Windows 策略环境未验证。强杀或断电可能留下未登记暂存/孤立目录；本层拒绝接管，没有自动清理机制。文件系统 rename 与 SQLite 不是跨资源事务；同用户恶意进程可直接篡改数据库，不属于可信数据库校验模型。当前无 TXT 一致性引擎、媒体解析或生成 ZIP。
