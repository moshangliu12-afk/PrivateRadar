# PrivateRadar v0.2.0-alpha.26

此版本为 Windows x64 预发布版本。alpha.25 → alpha.26 正式覆盖升级已完成真实 Windows 人工验收，未检测到数据库分裂。

### 新增能力

- **Obsidian Vault Export V1**：选择 Windows 本地 Vault，将聊天归档为带 YAML Frontmatter 的 Markdown 笔记；使用 Manifest 进行增量导出，跳过未变化内容并保护用户手动修改的笔记。PrivateRadar 仍为 Source of Truth，Vault 不反向同步。
- **PDF Export V1**：导出正式 PDF 文件，与 Markdown / JSON / TXT 共用 Export Core、日期范围及既有安全写入机制。
- **整理聊天给 AI 分析**：从聊天消息、Search 结果或 Evidence 选取材料，查看“准备分析的聊天记录”，预览、复制给 AI，或导出 Markdown / JSON。此功能不自动上传、不调用外部 AI API、不自动执行 Agent。
- **会话复选框多选**：无需 Ctrl 即可连续勾选、取消；显示数量，关闭后重开保留。普通文件导出与 Obsidian 共用选择。超过 50 个仅提示耗时，不设置选择数量硬上限，仍保留实际资源安全边界。
- **最近 6 条搜索**：仅记录实际提交的搜索，本地持久化、空白去重、重复置顶；点击直接重搜，支持单删、清空和重启保留。历史功能不新增外部网络请求。

### 改进

- 普通文件导出与 Obsidian Vault 归档分组更清晰，两个保存位置独立。
- 会话选择保留名称自动同步；会话显示名称、Search 与 Export 沿用已验收行为。
- 分析材料的加入、移除和预览操作采用已验收的最终界面文案与反馈。
- 保留 alpha.25 的 Conversation Label、Markdown / JSON / TXT、历史关键词重扫、规则累计有效命中、最近发现和最近扫描状态，以及 Search、Evidence、承诺候选和 Windows WorkBuddy Connector。

### 数据安全与真实升级

- **无新增数据库迁移，无新增数据库表，无新增依赖**；原有数据路径保持。
- **alpha.25 → alpha.26 正式 Windows 覆盖升级已人工验收通过，未检测到数据库分裂**。
- 原有聊天、Evidence、会话自定义名称与关键词情报保留；不删除历史数据、不重建数据库。
- 最近搜索复用原运行数据库的现有本地设置，仅保存搜索词，不保存搜索结果、聊天正文或 Evidence。
- 升级前请关闭 PrivateRadar、WorkBuddy 和连接器，完整备份并校验原数据目录，包括主库、存在的 WAL/SHM、Connector、Evidence、附件及其他文件；再在原安装位置覆盖升级。备份只用于离线恢复，不作为运行数据库。
- 本地材料交接与搜索历史不自动外传；应用其他可选远程 AI / Embedding 服务仍遵循原有[隐私边界](https://github.com/moshangliu12-afk/PrivateRadar/blob/v0.2.0-alpha.26/PRIVACY.md)。
