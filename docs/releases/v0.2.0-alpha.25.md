# PrivateRadar v0.2.0-alpha.25

此版本为预发布版本。

### 新功能

- 支持为会话设置 PrivateRadar 内部显示名称。
- 支持将聊天导出为 Markdown、JSON 和 TXT。
- 关键词规则支持手动扫描已有历史聊天。
- 关键词规则卡片显示命中数量、最近发现时间、最近扫描时间和状态。

### 改进

- 历史扫描支持重复执行并自动去重。
- 规则修改后，可重新扫描并按当前规则重新计算历史命中。
- 会话自定义名称用于现有相关展示和聊天导出。
- 规则内容变化后，卡片会提示尚未扫描当前规则。

### 数据与隐私

- PrivateRadar 继续优先在本机处理和保存数据。
- 本版本不改变现有聊天来源事实，不创建第二套运行数据库。
- 升级前请关闭 PrivateRadar 和 WorkBuddy，完整备份并校验现有数据目录，再使用正式安装包覆盖升级。请勿删除 AppData 数据目录或从备份运行数据库。
