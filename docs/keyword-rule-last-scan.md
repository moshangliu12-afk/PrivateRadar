# 关键词规则最近扫描

基线为 `a9e275e1f4f2c02b247ad1cbfeba384187abb65e`。与规则卡片统计合并为一次桌面候选和一次人工验收，旧统计候选不再单独验收。

最近扫描读取真实手动任务表 `keyword_rescans`，不使用正常导入的 `keyword_radar_runs`。按组分区、按 rowid 倒序选一条，与原扫描服务读取最新任务的顺序一致；同秒任务和系统时钟回拨不会误选旧记录。与原统计及关键词在同一条 SQL 中取得，没有逐卡查询、缓存、字段或数据库迁移。

复用原扫描服务的只读状态投影，包括原有进程中断识别。源代码仅导出原投影及其类型，没有修改扫描执行、取消、恢复、matcher 或命中写入逻辑。状态映射只包含真实枚举：`running` 扫描中、`complete` 成功、`failed` 失败、`cancelled` 已取消；未知值安全显示状态未知。

运行中使用 `started_at`；成功、失败、取消优先使用 `finished_at`。中断等未记录结束时间的情况回落到真实开始时间，返回 `timeSource` 并通过提示说明，绝不制造结束时间。界面直接复用关键词雷达原 `timeLabel`。无记录显示尚未扫描，异常时间显示时间未知，不显示内部枚举或空值字符串。

最近发现继续来自有效命中的 `matched_at`，消息发生时间继续来自原来源事实，二者没有变化。重复扫描可更新扫描时间，但不会因此重置最近发现或重复增加命中。

同次查询取得当前名称、启用词及持久规范词，与任务原规则快照通过原契约解析器核对。规则改名、启停词、添加词或停用组后，旧扫描仍显示原操作时间与状态，但明确标记“尚未扫描当前规则”；无法核对的旧快照也采用该安全标记。重新扫描后恢复当前快照状态，不引入规则版本系统或自动重扫。

扫描开始后复用原规则列表刷新一次，完成、失败或取消仍复用现有轮询和完成刷新。载入时已知运行任务的编号传给原轮询，以覆盖首轮读取时任务恰好结束的情况。没有新增事件总线、全局任务系统或每卡 last-scan 查询。

归档沿用现有语义：从活动卡片区域移除，不返回或显示活动统计与扫描状态；折叠归档记录与原运行历史保留。查询只读，不修改原规则、命中、消息、关系、Evidence、会话标签、FTS 或数据库位置。

统一候选包括既有冻结功能、规则卡片统计和最近扫描。先关闭 PrivateRadar、WorkBuddy 及连接器，完整备份整个用户数据目录并核验，再复制到自己的 Documents 逐文件核验后手动启动。只做统一 A 至 L 验收，不重新完整验收冻结功能；不发布或进入下一功能。
